# Integrated Storage SP
A single-player shared storage mod for Palworld that allows crafting and building to use materials stored across all bases in the same guild.

## Compatibility
- Palworld: 1.0.4
- UE4SS: v3.0.1 Beta #0 / 2281fa31
- Mode: Single-player only

## Features
- Share chest materials across all bases in the same guild
- Works with crafting
- Works with building
- Automatically discovers base storage
- Handles storage changes and map reloads
- No manual hotkey required

## Installation
Requires UE4SS for Palworld.

Place the mod folder under:

```
Palworld\Mods\NativeMods\UE4SS\Mods\IntegratedStorageSP\
```

Final structure:
```
IntegratedStorageSP/
└─ Scripts/
   └─ main.lua
```
